> **"GAME-WIRE"** is a fully automated, real-time, and modern international gaming and tech news aggregator platform. It collects breaking news directly from reliable RSS feeds of top-tier gaming portals and tech sites, organizing them neatly by category. It provides an exceptional reading experience in a clean user interface without any intrusive advertisements or third-party brand distractions.

## 🎖️ Key Features

### 1. 🔄 Automated Real-Time Sync (24/7 Automation)
- **GitHub Actions CI/CD:** Automatically fetches breaking gaming and tech news and updates the site via background workflows without manual intervention.

### 2. 📑 Precise Category Organization
- Automatically organizes reports into Gaming, Esports, Hardware, Console, PC Gaming, Tech & AI, and Reviews.

### 3. 🛡️ Privacy & Content Sanitization
- Delivers clean news under our own independent branding without external site redirections. Readers can read full articles instantly via in-site pop-up modals.

### 4. 🚫 Duplicate & Image Protection
- Advanced duplicate filtering and image pruning systems prevent duplicate stories or repetitive imagery.

### 5. ⚡ Lightweight & Fast Performance
- Built with Node.js, Tailwind CSS, and Alpine.js without heavy databases or bloated third-party libraries, ensuring lightning-fast loading speeds.

## 🛠️ Tech Stack

- **Frontend:** HTML5, Tailwind CSS, Alpine.js, FontAwesome, Google Fonts (Rajdhani & Inter).
- **Backend Automation:** Node.js (Built-in modules - zero external npm overhead).
- **Hosting & CI/CD:** GitHub Pages & GitHub Actions (24/7 Autonomous Sync).
