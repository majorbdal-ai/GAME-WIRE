# GAME-WIRE 🎮⚡
> International Gaming & Tech News Hub featuring 100% in-site reading experience, real-time sync, and sleek cyberpunk UI.

## Overview
**GAME-WIRE** is a next-generation international gaming news aggregator and media portal. Built with Tailwind CSS and Alpine.js principles, it delivers comprehensive coverage of AAA titles, esports championships, hardware benchmarks, and tech news with zero external redirects or intrusive ads.

## Key Features
- **100% In-Site Reading:** Read full reports, breaking news, and developer interviews instantly inside responsive modal overlays.
- **Esports & Launch Trackers:** Real-time scoreboard widgets and hardware launch tables.
- **Dual Section Coverage:** Dedicated feeds for Gaming and Tech & Hacking.
- **Automated GitHub Actions CI:** 24/7 automated RSS and news ingestion pipelines.
- **Fully Responsive & Lightning Fast:** Optimized for desktop and mobile displays with fluid cyberpunk aesthetics.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+), Alpine.js, Font Awesome, Google Fonts (Rajdhani & Inter).
- **Data Architecture:** JSON-driven dynamic news repository (`data/news.json`).
- **Hosting & CI:** GitHub Pages with automated workflows.
